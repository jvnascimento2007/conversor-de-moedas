# Conversor de Moedas

Aplicação web para conversão de moedas em tempo real.

## Tecnologias
- HTML5, CSS3 e JavaScript puro.
- API: [AwesomeAPI](https://docs.awesomeapi.com.br/).

## Funcionalidades
- Conversão universal entre BRL, USD, EUR e JPY.
- Formatação de moeda nativa (Locale).
